# Centrolit — Cotizador y Cuadro de Mando (web)

Versión web de la app del Grupo Centrolit. Cualquiera puede abrir esta página, pero sin una cuenta de
Google con permiso sobre los ficheros del Grupo solo funciona el modo demo (datos ficticios).

Código fuente: [centrolit-app](https://github.com/carlosdelco/centrolit-app) (repo privado).
Se publica aquí automáticamente con `npm run deploy:web` desde ese repo — no editar directamente.
